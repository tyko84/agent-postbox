# Everything that is installed before the release artifacts are written: the `build`
# front end and the two packages it needs, each pinned to one version AND to the
# SHA-256 of its wheel. Install with
#
#     python -m pip install --require-hashes -r requirements-build.txt
#
# pip then refuses any file whose hash is not listed here, and any package that is
# not listed at all. The three are pure Python: one wheel each, the same file on
# Linux and macOS. Python 3.11 or newer (on 3.10 `build` also needs tomli, which is
# not listed: use requirements-dev.txt there). The build backend, setuptools, is not
# installed by this file; scripts/repro_build.py fetches it and checks it against
# build-constraints.txt. See docs/packaging.md, The build tools.
#
# `build` is pinned in requirements-dev.txt as well; the two pins must agree
# (test_packaging.py checks). To move a pin: change the version and replace the hash
# with the sha256 of the wheel as https://pypi.org/pypi/<name>/<version>/json lists it.
